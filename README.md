Entry for the [make.fun bounty "One-Liner Marathon"](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2): a program that writes one one-line comedy joke to `/output/entry.txt`.

The joke: "I told my AI assistant to be more human. Now it ignores my messages and blames the Wi-Fi."

Run it with `python3 main.py` (writes to `/output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR` when set).
